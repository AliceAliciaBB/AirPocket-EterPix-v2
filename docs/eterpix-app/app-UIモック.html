EterPix-app モック(NudeNyang タブレット内)

docs/VRC-NudeNyangTablet_app.md の画面構成を、Unity側の UI 規則(全部長方形, 線なし, 不透明, Bold1種. 写真への文字の重ね合わせだけは指示による例外)で作り直しました. 起動画面でロードし、「push to start」で スワイプ画面 に入ります. スワイプ(ドラッグ)か、写真の下の帯のボタン、矢印キーで操作できます. 投稿と写真は架空のサンプルです. 実際のアプリでは、本番の vrc-api v1(/api/vrc/v1/public)から取得します.

画面構成(ドキュメントどおり)

  • 共通: i(インフォメーション), グループ(グループ説明), テーマ切り替え(白/黒). ロード中も開けます. 画面を開くボタン(i / グループ / ♡)は、開いている間 X に変わり、同じボタンを押すと元に戻ります. テーマは押すだけで切り替わります.
  • 1 起動画面: ロゴ, 紹介文, 進行度. 終わると「push to start」が出ます.
  • 2 スワイプ画面: 写真の下の帯が、スワイプの説明であり、押せるボタンでもあります. ドラッグ中は、向かう側の帯が色づきます.
  • 3 気になる投稿一覧: 右スワイプした投稿のリストです. ♡ から開き、X を押すと スワイプ画面 に戻ります. 1件は「画像 | 説明」と「画像(続き) | ボタン」の2段で、画像は中央を1:1に切り取っています. ボタンは右寄せで「WEB | 高画質 | ポータルを開く」の順です(ポータルは世界IDが無い投稿では出ません). WEB・高画質は押しても文字を変えません(最初に確保した領域の中で表示するため). 高画質は押すと面の色だけが変わります. 動作は仮です.

Unity側の規則の反映

  • 要素はすべて長方形. 角丸・ピル形なし. 線なし. 区切りは余白(単位8, 外側16).
  • 面の色を持つのはボタンだけ. 色は不透明、文字は1色(例外: 写真に重ねる情報の帯だけ50%半透明).
  • フォントは Noto Sans JP Bold のみ. 強弱はサイズ(13 / 16 / 24 / 40).
  • 写真は大きく表示し、投稿者名・説明・ワールド名を写真の下端に重ねます(背景色の50%半透明). Unity側の「写真に重ねない」規則への、指示による例外です. スワイプの表示は写真の外(下の帯)のままです.
  • 写真を押すと、モニター全体に拡大します(UIあり: 投稿者名・ワールド名の情報帯だけを写真に重ねる). もう一度押すとUIを隠して写真だけになり、もう一度押すと元の画面に戻ります. 気になる投稿一覧の画像を押しても同じ流れで拡大し、最後は一覧に戻ります. 拡大は Pad(K-4)と同じく、写真の長辺をモニターの長辺に、短辺を短辺に合わせ、縦横が食い違うときは90°回します(縦写真も横写真も対象). 上の「向き」を切り替えて確認できます.
  • 配色は eterpix_theme の黒 #141414 と白 #FAFAFA. アクセント #9D6FFF の上の文字は #141414.
  • 通信エラー・読み込み中・0件は、写真枠の中に表示. ヘッダーは常に表示. 読み込み中は枠が明滅します(上の「状態」で確認).

カードと vrc-api v1

poid投稿1件 = カード1枚
usna + ussf投稿者名と後ろの[称号]
wona + wopfワールド名と、手入力の印【追記】
woidNudeNyangの既存ポータルに渡す世界ID. 空なら「ポータルを開く」を出さない(例: Cafe Marmalade)
coid / copo写真がどのコラージュの何番目か(画面には出さない)

コラージュは別々の投稿の写真を6枚貼り合わせた、取得のための梱包です.

仮のものと確認したい点

  • サンプルデータ: 実際のアプリは vrc-api v1 を使います. このモックは、同じJSONのキー名で作った架空の投稿20件(4コラージュ)を、Unityと同じく UV 切り出しと回転(coro)で表示しています. このページからは外部へ通信しません(写真・名前・ワールド名はすべて架空です).
  • 仮: グループ説明の文面, ロゴ(2×3の格子).
  • 追加: 写真タップで拡大, 帯のボタン, 矢印キー, 一覧の「ポータルを開く」.
  • 確認: 「ロード終了後 [2] へ移る」と「push to start」の関係. このモックはボタンで移ります.
  • ポータル: NudeNyang の既存機能(NudeNyangTravelPortal)をそのまま使い、EterPix-app では作りません. 床を指してクリックで配置, 同時に1つ, 再配置まで30秒, 15秒で消えます. ボタンの文字は「ポータルを開く」→(押すと)「ポータルを置く」→「ポータル開いた」と進み、しばらくして元に戻ります(モックは時間で進めています).
  • 未決: 「気になる」をサーバーに保存するか(保存するなら Web 側の API と DB の追加が要ります).
  • 未確認: VRChat内でのドラッグ操作の感触. 帯のボタンを併設しているのはそのためです.
